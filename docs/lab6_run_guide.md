# Как запустить прототип (ЛР №6)

## Требования
- Node.js и npm.
- Распакованный репозиторий `price-analyzer`.

## Запуск на macOS

1. Открой Terminal и перейди в папку frontend:

   ```bash
   cd путь/к/price-analyzer/frontend
   ```

2. Установи зависимости (при первом запуске):

   ```bash
   npm install
   ```

3. Запусти приложение:

   ```bash
   npm run dev
   ```

4. Открой адрес, который Vite покажет в терминале (обычно `http://localhost:5173`).

## Что продемонстрировать

1. Раздел «Обзор»: показатели, график динамики и сравнение последних цен.
2. Раздел «Каталог товаров»: поиск и добавление нового товара.
3. Кнопку «Добавить цену»: ввод товара, магазина, цены и даты.
4. Раздел «Сравнение цен»: минимум, максимум и среднее по последним ценам магазинов.
5. Повторное добавление записи для того же товара, магазина и даты — должна появиться ошибка о дублировании.
6. Обновление страницы — сохранённые в браузере записи должны остаться.

Прототип использует демонстрационные данные и `localStorage`. В нём нет подключения к серверу Spring Boot и PostgreSQL.
